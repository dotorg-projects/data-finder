# Support

## Getting Help

Use GitHub issues for bug reports, feature requests, and questions about expected behavior:

https://github.com/dotorg-projects/data-finder/issues

Before opening a new issue, please search existing issues and include a minimal reproduction when possible.

## Security Issues

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead.

## Commercial Support

EP Finder is maintained as an open source project. Commercial support is not currently offered by this repository.
